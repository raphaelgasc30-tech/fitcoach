# 🏋️ FitCoach

> Application web de coaching sportif personnalisé — gratuite, simple et efficace.

---

## 🚀 Démo en ligne

👉 [Accéder à l'application](https://raphaelgasc30-tech.github.io/fitcoach)

---

## 📋 Fonctionnalités

- 💪 **Suivi d'entraînement** — enregistre tes séances et suis ta progression
- 📅 **Générateur de programmes** — crée des programmes adaptés à tes objectifs
- 🔥 **Calculateur de calories** — estime tes besoins caloriques journaliers
- 📊 **Calcul de l'IMC** — évalue ton indice de masse corporelle instantanément

---

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript

---

## 📦 Installation

Aucune installation requise ! Il suffit d'ouvrir le fichier dans ton navigateur :

```bash
# Clone le dépôt
git clone https://github.com/raphaelgasc30-tech/fitcoach.git

# Ouvre le fichier
open application\ fitcoach.html
```
